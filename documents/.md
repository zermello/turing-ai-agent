Test Documents

This directory contains sample files used to test TURING’s document-reading capabilities.

These files are test fixtures and are included only for development and automated testing.

Supported Formats

The sample files cover the document formats currently supported by TURING:

* .txt — Plain text
* .md — Markdown
* .json — JSON
* .csv — CSV
* .pdf — PDF
* .docx — Microsoft Word document

Purpose

These files are used to verify that each document reader can:

* Open valid files
* Extract their contents correctly
* Handle different document structures
* Return the expected data format
* Handle invalid paths and file types appropriately

They do not contain sensitive or real user data.
